# 김상혁 취업용 포트폴리오 — 작업 방향 (개정)

## 1. 기준
- 과제: "나를 소개하는 한 페이지" (회사 소개가 아닌 **나 자신** 소개)
- **기준 시점: 2026-08-25** — 전역(2026-07), ALEPH 시작(2026-08-11) 후 2주 차. 이 날짜 이후의 기록·과제(8번 패스키, 9~13번, 9월 기록)는 쓰지 않는다.
- 사실 근거: a-pr-site의 이력 기본정보·리추얼 기록 원문·과제 목록. 근거 없는 수치·경험은 넣지 않는다.

## 2. 페이지 구성 (취업 포트폴리오 양식)
1. 상단 내비 + 움직임 줄이기 버튼
2. 첫 화면: 이름 / 한 줄 소개 / 지금 하는 활동 / 직접 열어 볼 근거 (1366×768에서 스크롤 없이 3요소 노출)
3. 기술 스펙 (2주 차에 직접 쓴 것만)
4. 참여 프로젝트 — 과제 1~3, 상황·행동·결과 아코디언
5. 군 경력 — 병사·부사관·GOP 근무·ALEPH 타임라인
6. 기록으로 확인되는 강점 3가지
7. 연락·소스 (GitHub)

## 3. 웹페이지에서 제외 (별도 PDF 제출)
- 공개 범위 점검표 → `SCOPE.md`
- 짧은 확인 방법 4줄, AI와 나의 판단 3줄 → PDF에서 작성

## 4. 검증 기준
- 1366×768 / 1920×1080 첫 화면 3요소, 가로 넘침 0, 태블릿·모바일도 넘침 0
- 링크·Tab·제목 단계·대비·콘솔 오류 0, 아코디언은 클릭/Enter/Space 동일
- 비밀값·개인정보 검색 0건 → `CHECK.md`
