# 카드 1 — 대상과 공개 범위

**한 문장:** 이 페이지는 수업·프로젝트를 함께할 동료와 담당자에게, 내가 어떻게 문제를 풀고 무엇을 만들어 왔는지 근거와 함께 보여준다.

## 공개할 것
1. 실명(표시 이름)과 한 줄 소개
2. 강점 3개(상황·행동·결과)와 취향
3. 참여 중인 교육과정(SKT ALEPH)과 군 복무 이력(육군)
4. 직접 만든 결과물 요약과 공개 가능한 링크

## 공개하지 않을 것
1. 생년월일, 주소, 전화번호
2. 학번, 이메일 원문
3. 비밀번호·토큰·API 키, 타인의 얼굴·이름이 나오는 이미지

## 공개 주소
- (배포 후 기입) — 새 시크릿 창에서 로그인 없이 열리는지 확인
