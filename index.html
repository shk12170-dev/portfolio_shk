상황
처음 온 사람이 계정 없이 볼 수 있는 소개 페이지가 필요했습니다.
행동
정적 HTML로 소개 페이지를 만들고 GitHub Pages에 배포했습니다.
결과
로그인 없이 열리는 공개 페이지를 확보했습니다. 지금 보고 있는 이 페이지가 그 개선본이며 Vercel로 배포했습니다.
수정 전
처음 초안에는 양수 tabindex가 15개 있었고, 제목 구조(h1)가 없었으며, 근거를 댈 수 없는 수치가 들어 있었습니다.
수정 후
양수 tabindex를 모두 없애 문서 순서대로 이동하게 했고, h1부터 이어지는 제목 구조를 만들었으며, 근거 없는 수치는 삭제했습니다.
스택
HTML · CSS · JavaScript · GitHub Pages(초안) · Vercel(개선본)

상황
새 게임을 시작할 때 무엇을 초기화하고 무엇을 남길지 규칙이 없어 값이 뒤섞였습니다.
행동
보존할 값과 초기화할 값의 규칙을 문서로 정하고, 변경 전과 후로 각각 10회씩 플레이해 기록을 비교했습니다.
결과
규칙 문서와 20회 플레이 기록표를 남겨, 값 하나의 변경이 결과에 주는 영향을 근거로 설명할 수 있게 했습니다. 공개 화면 열기 (새 탭)
스택
JavaScript · LocalStorage · Vercel

상황

행동

결과

군 경력 — 직업군인 시절

2017년 10월 입대, 병사와 부사관으로 약 9년 군 생활을 했고 2026년 7월 전역했습니다.

  1. 2017.10.23 ~ 2019.07.01

    육군 병사 복무

    병사로 입대해 복무를 마치고 만기 전역했습니다.

  2. 2019.07.02 ~ 2026.07.01

    육군 부사관 복무

    전역 직후 부사관으로 임관해 군 생활을 이어갔습니다.

  3. 2022.04.18 ~ 2022.08.15 (부사관 복무 중)

    GOP 근무와 복귀

    상황
    2주에 하루 외박을 빼면 근무와 휴식의 경계가 뚜렷하지 않은 환경이었습니다.
    행동
    생활 리듬을 다시 정비하기 위해 원소속 부대로 복귀했고, 파견 근무를 거치며 안정적인 리듬을 찾았습니다.
    결과
    남은 복무를 마치고 2026년 7월 전역했습니다.

  4. 2026.08.11 ~

    SKT ALEPH 교육과정

    AI를 다룰 수 있으면 쓸 데가 있겠다는 생각으로 신청해 웹 개발을 배우고 있습니다.

기록으로 확인되는 강점

막혀도 방법을 만든다

상황 8월 실습 중, 바이브코딩으로 찾은 명령어를 입력하자 오류가 났습니다. 그 오류를 다시 물으면 또 다른 오류가 나와 해결 방법을 찾지 못했고, 어느 단계를 하던 중이었는지 잊을 만큼 갈피를 잡기 힘들었습니다.

행동 쉬는 시간에 "나는 할 수 있다"고 속으로 외치고 다시 화면으로 돌아갔습니다.

결과 8월 25일 마무리 기록에 그 방법을 적었고, 다음 날 아침에 한 번 더 쓰기로 했습니다.

질문하기 쉬운 분위기를 만든다

상황 매일 아침 함께 수업을 듣는 동료들과 하루를 시작합니다.

행동 부드럽게 말을 건네고 편하게 질문을 주고받았습니다.

결과 8월 21일 동료가 "질문이 자연스러운 분위기로 부드럽게 만들어준다"고 적어 주었습니다.

고친 이유를 검사로 남긴다

상황 극단 입력에서 화면이 깨졌습니다.

행동 12가지 검사표를 만들어 하나씩 넣어 보고 수정 전후를 기록했습니다.

결과 검사표와 수정 전후 비교 문서가 공개 저장소 (새 탭)에 남아 있습니다.
